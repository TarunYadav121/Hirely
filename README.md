# Hirely - Job Portal

## Overview
Hirely is a modern job portal web application designed to connect job seekers with employers. The platform features user profiles, job listings, company information, and career news.

## Features
- **User Profiles**: Browse through candidate profiles with their skills, education, and salary expectations
- **Job Search**: Filter jobs by role, location, and job type
- **Company Listings**: Explore top companies and their current job openings
- **Career News**: Stay updated with the latest trends in the job market

## Pages
1. **Front Page** (`Front.html`): Landing page with user profiles, company listings, recent job posts, and career news
2. **Job Search** (`index.html`): Search and filter through available job listings
3. **Login** (`login.html`): User authentication page
4. **Registration** (`registration.html`): New user registration

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome for icons

## Getting Started
1. Clone the repository
2. Open any of the HTML files in your web browser to explore the application
3. No additional dependencies or setup required

## File Structure
- `Front.html` & `Front.css`: Landing page
- `index.html` & `styles.css`: Job listings page
- `login.html` & `login.css`: Login page
- `registration.html` & `registration.css`: Registration page
- `script.js`: JavaScript functionality for job filtering

## Features Implemented
- Interactive job filtering by role, location, and job type
- Responsive design for various screen sizes
